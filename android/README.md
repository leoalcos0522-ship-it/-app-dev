# Android setup (Android Studio)
1. Gumawa ng folder: `app/src/main/assets/` (right-click `main` > New > Directory > assets).
2. Kopyahin ang `index.html` (root ng repo) doon.
3. Palitan ang laman ng `MainActivity.kt` ng `android/MainActivity.kt` dito.
4. Run (▶) sa emulator o phone (USB debugging).
