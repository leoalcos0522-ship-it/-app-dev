# ChaiCentral

Centralized business management system with data analytics for PM Chai Café (STI College Caloocan capstone).

Android app built with Kotlin, Jetpack Compose and Room. Screens: Dashboard (today's revenue, top sellers, low stock), Inventory (add/restock/delete items), Sales (tap-to-sell point of sale with stock deduction).

## Open in Android Studio
1. File → Open → select this folder and let Gradle sync (Android Studio prompts to create the Gradle wrapper if missing; JDK 17).
2. Run the `app` configuration on an emulator or device (minSdk 26).
